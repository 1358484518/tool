变更:
1. 生产版本（当前 d0e5a75，版本 2.31）

窗口标题的中文保留了 %1。以前写死成 V2.22，打开时会出现 QString::arg: Argument missing，现在显示当前版本。
可以同时识别多只 ST-LINK，按序列号并行下载和擦除，每只的日志分开存。
设置改存到程序旁边的 TMX/TMX_TOOL.ini，不再写注册表。
DA 关断和回归脚本可以用十六进制序列号指定 ST-LINK。

2. 研发主版本（当前 aeda371，版本 2.31）

接收窗口只画当前这一屏，大约每 16 毫秒刷新一次。历史放在 8MB 环形缓冲里，丢旧数据时不再整段搬家。
串口接收改用这个窗口。连续来数据时按固定间隔打包，不再每次来包都重新计时，界面不会攒满才跳一次。
缓冲里存原始字节和时间戳。勾选「十六进制显示」或「时间戳」会立刻重画已有内容；时间戳保持文字，不转成十六进制。串口和网络页都是这样。
自动保存写入时间戳和原始字节，勾选十六进制不改这个文件。点「保存日志」时才按当前勾选生成文本。
关掉程序后，串口和网络的发送框内容会记在 ini 里，下次打开再填回去。
接收窗口放到 common，串口和网络共用。串口页自己管线程、打开端口、保存日志和 YModem，主窗口只放页签。
设置同样改存到 TMX/TMX_TOOL.ini。DA 脚本同样可以用序列号指定 ST-LINK。

3.安全固件更新

SECC-AC、RD0047、RD0050、RAT、G0、EAW 改的是同一处，各分支自己的串口和 Flash 引脚没有动。
ISO 15118-20 的 mTLS 握手要在安全侧做多次 P-521 ECDSA 验签。这次只改计算方式，算法和对外接口没有变。
crypto_config_default.h 里 MBEDTLS_ECP_FIXED_POINT_OPTIM 从 0 改为 1。验签要算 u1·G + u2·Q，G 是曲线固定生成元。打开之后乘 G 走预计算表；u2·Q 仍是普通点乘。签名里的 k·G 走同一条快路径。
crypto 分区的 CMakeLists.txt 在编 TF-PSA-Crypto 时把构建类型写成 RelWithDebInfo（-O2）。原来平台把这套库固定成 minsizerel（-Os）。编完会恢复原来的构建类型，所以 BL2 和 NS 的优化级别不变。
