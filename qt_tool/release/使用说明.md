# 地木升调试助手发布通知

企业微信机器人「地木升调试助手」把发布说明发到群里。研发和生产各记一个群，各有一份说明。

研发群已经记下，是「研发-项目例会」。生产群还没有。

## 每次发布

1. 把安装包放到已经定好的位置。
2. 改对应的说明文件。研发改 `RELEASE-研发.md`，生产改 `RELEASE-生产.md`。
3. 双击 `发布研发通知.bat` 或 `发布生产通知.bat`。

两个版本一起发时，两个 bat 都点。先确认 zip 已经在下载路径里。

说明按这个格式写。版本、下载、至少一条变更必须有。说明可以空着，空着就不会出现在群消息里。

```text
版本: 2.21
下载: \\server\TMX\current\地木升调试助手研发版本V2.21.zip

变更:
- 下载页补了 RD0050
- 发布烧录成功后自动做 DA 认证

说明:
先关掉正在运行的程序，整包解压覆盖。
只换 exe 会缺 ACSF 或 da。
```

群里看到的是：

```text
地木升调试助手 研发版 V2.21

下载：\\server\TMX\current\地木升调试助手研发版本V2.21.zip

变更：
- 下载页补了 RD0050
- 发布烧录成功后自动做 DA 认证

说明：
先关掉正在运行的程序，整包解压覆盖。
只换 exe 会缺 ACSF 或 da。
```

变更每条以 `- ` 开头。说明里的每一行原样发出。

## 记下生产群

1. 把「地木升调试助手」拉进生产通知群。
2. 双击 `记下生产群.bat`，窗口停住。
3. 马上在那个群里 @地木升调试助手，发一句「收到」。
4. 群里出现「已连上。之后生产版发布说明会发到这个群。」就说明记好了。窗口可以关掉。

换群、机器人被移出群，用同样的步骤重新记。研发群用 `记下研发群.bat`。

同一个机器人同一时间只能有一个连接。记群的窗口还开着时，不要再点发布。

## 本机文件

| 文件 | 作用 |
| --- | --- |
| `RELEASE-研发.md`、`RELEASE-生产.md` | 每次改的发布说明 |
| `发布研发通知.bat`、`发布生产通知.bat` | 把说明发到对应的群 |
| `记下研发群.bat`、`记下生产群.bat` | 第一次或换群时记下群 |
| `release.local.json` | Bot ID 和 Secret，只留在本机 |
| `release.state.json` | 已经记下的群，只留在本机 |

`release.local.json` 和 `release.state.json` 不要提交，也不要发到群里。Secret 换过之后，打开 `release.local.json`，改 `botId` 和 `secret`。

机器人在企业微信里：工作台 → 智能机器人 → 地木升调试助手 → API配置。连接方式保持长连接。

## 在其他电脑发布

可以。那台电脑能上网即可，不必登录企业微信。把整个 `release` 文件夹拷过去，里面要带上 `release.local.json` 和 `release.state.json`。少了第一份连不上机器人，少了第二份不知道往哪个群发。

拷过去之后，改说明、双击发布 bat，和这台电脑一样。

只在一台电脑上点。这个机器人同时只能有一个连接，两台一起点时，后连上的会把先连上的挤掉。点一次会连上、发出、再断开，发完就可以在另一台接着用。
